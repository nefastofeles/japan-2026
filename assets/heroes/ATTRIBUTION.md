# Landmark photos

These are **not trip photos**. They are openly licensed pictures of the
places we will visit, used as destination banners until a family photograph
exists for that day.

Each file is a resized, recompressed copy of a Wikimedia Commons original.
Cropping for the banner happens in CSS (`object-fit: cover`).
